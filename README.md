# 👾 Mantasha | Pixel Portfolio

A retro, pixel-themed single-page application (SPA) portfolio built to showcase my projects, skills, and background as a Computer Science student and software developer.

## ✨ Features
- **Pixel Art Aesthetic:** Styled using custom pixel fonts (*Pixelify Sans*, *Fredoka*) and stepped CSS shadow boxes.
- **Client-Side SPA Routing:** Instant view-switching between Home, About, Skills, Projects, and Contact sections without page reloads.
- **Fully Responsive:** Mobile-friendly layouts tested across smartphones, tablets, and desktop displays.
- **Accessibility Ready:** Built with semantic HTML5 elements and screen-reader live announcements.

## 🛠️ Built With
- **HTML5** (Semantic structure & ARIA attributes)
- **CSS3** (Custom properties, CSS Grid, Flexbox)
- **JavaScript (ES6+)** (Dynamic navigation & SPA routing logic)
